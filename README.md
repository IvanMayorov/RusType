# RusType

Локальная русская диктовка для Mac с Apple Silicon и macOS 14 или новее. Удерживайте Fn, пока говорите. Когда вы отпустите клавишу, RusType распознает фразу и введёт её у курсора. Если курсор стоит посреди предложения, например после запятой, фраза продолжит текст со строчной буквы. Для распознавания используется GigaAM v3 E2E RNN-T Q8_0.

## Установка

1. Скачайте [RusType-0.2.0-macOS-arm64.zip](https://github.com/IvanMayorov/RusType/releases/download/v0.2.0/RusType-0.2.0-macOS-arm64.zip) и распакуйте архив.
2. Запустите `Prepare-RusType.command` из распакованной папки. Понадобится интернет для загрузки официального образа Golosok 1.13.11 (около 279 МБ). Скрипт сверяет SHA-256 образа, извлекает модель и движок, затем проверяет подпись готового приложения.
3. Переместите созданный `RusType.app` в «Программы». Если другое приложение диктовки использует Fn, завершите его. Откройте RusType и предоставьте доступ к микрофону и к «Универсальному доступу». Сборка подписана локальным сертификатом, без нотарификации Apple. Если macOS блокирует открытие, проверьте источник загрузки и используйте «Открыть всё равно» в разделе «Конфиденциальность и безопасность».

## Настройки

Нажмите на значок волны в строке меню, чтобы открыть панель. Здесь можно выбрать микрофон, скопировать последнюю расшифровку или добавить замену, например «си эр эм» → «CRM». Обычная диктовка сохраняет содержимое буфера обмена. Последняя фраза доступна для копирования до выхода из приложения.

## Сборка из исходников

На Mac с Apple Silicon установите Xcode Command Line Tools. В каталоге репозитория выполните:

```sh
bash scripts/runtime.sh Runtime
RUSTYPE_SIGN_IDENTITY=- ./build.sh
```

Приложение появится в `build/RusType.app`. Для повторных сборок можно передать SHA-1 постоянного сертификата подписи кода через `RUSTYPE_SIGN_IDENTITY`. При подписи без сертификата macOS может повторно запросить разрешения после пересборки.

## Компоненты

Интерфейс, обработка Fn, словарь и вставка реализованы в этом репозитории. Модель [GigaAM v3](https://huggingface.co/ai-sage/GigaAM-v3) и исполняемый файл `transcribe-cli` в формате для Apple Silicon извлекаются из [релиза Golosok 1.13.11](https://github.com/Berliner187/Golosok/releases/tag/v1.13.11).
